# AssessorSearch

Search U.S. property records by address or parcel number.

[AssessorSearch](https://assessorsearch.com) brings together owner, mailing-address, tax, sale, deed and property-detail fields from public property records. Coverage and available fields vary by county and property.

Use the website for property research, the Property Data API for integrations, or the hosted MCP server to look up records from an AI assistant. MCP access requires an active Property Data API plan.

- [Search property records](https://assessorsearch.com)
- [Browse the county assessor directory](https://assessorsearch.com/property-records)
- [Property Data API](https://assessorsearch.com/property-data-api)
- [Connect an AI assistant with MCP](https://assessorsearch.com/mcp)
- [MCP setup and tool reference on GitHub](https://github.com/assessor-search/assessorsearch-mcp)
